🤖 AI Sales & Customer Support Agent — Senjer Fragrances

An AI-powered Sales & Customer Support Agent built for Senjer Fragrances, a perfume brand.

The application helps customers get product information, perfume recommendations, and answers through a simple AI-powered conversation.

🚀 Features
💬 Answers customer questions
🌸 Provides perfume and product information
🎯 Recommends suitable products
📚 Uses RAG to retrieve relevant brand information
🤖 Generates natural AI responses
❌ Avoids generating information when the required knowledge is not available
🖥️ Interactive Streamlit interface
🛠️ Technologies
Python
Streamlit
RAG
LLM
Generative AI
APIs
Vector Database

🎯 Purpose

This project demonstrates how Generative AI and RAG can be used to build a real-world sales and customer support solution for a perfume brand.
